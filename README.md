# ruconmd

Консольный редактор Markdown для Linux и Windows (x86_64) с режимами правки и просмотра.

| | |
|---|---|
| Версия | 0.1.0-beta.3, предварительная ([изменения](CHANGELOG.md)) |
| Язык реализации | Rust, минимальная версия 1.90 |
| Интерфейс | русский, английский |
| Поставка | один исполняемый файл; для Linux статический (musl) |
| Проверка | автотесты в Linux и Windows (ConPTY); вручную Windows Terminal (основные сценарии) и один терминал Linux (клавиши, буфер обмена) |
| Лицензия | MIT OR Apache-2.0 |

## Возможности

### Режимы

- Правка: исходный текст с подсветкой разметки. Просмотр: отрисованный документ на весь экран.
- Переключение: F5 или Ctrl+E в обе стороны. Позиция в документе сохраняется.
- Просмотр строится из текущего буфера, включая несохранённые правки. Менять в нём можно только отметки задач.

### Правка

- Отмена и повтор с группировкой набора по словам.
- Выделение клавишами и мышью, системный буфер обмена (при недоступности внутренний).
- Поиск и замена: учёт регистра, регулярные выражения с группами.
- Продолжение списков, нумерации, задач и цитат по Enter, отступы по Tab, обёртка выделения в жирный, курсив и ссылку.
- Перемещение по графемам, учёт ширины широких символов.

### Просмотр

- CommonMark и GFM: таблицы, задачи, сноски, зачёркивание, автоссылки, предупреждения, метаданные YAML.
- Подсветка кода по языку блока.
- Формулы LaTeX преобразуются в Unicode; непреобразуемые выводятся исходным текстом.
- Локальные картинки PNG, JPEG, GIF (первый кадр), WebP по протоколам Kitty, iTerm2, Sixel. Без поддержки графики выводятся подпись и ссылка.
- Переход по якорям и локальным файлам Markdown с историей. Ссылки http, https и mailto открывает системное приложение, остальные схемы запрещены.
- Оглавление и поиск по отрисованному тексту.

### Панель файлов

- `ruconmd КАТАЛОГ` открывает каталог, F4 или Ctrl+O показывает панель слева, переходит в неё и закрывает её.
- Дерево каталогов; по умолчанию файлы md, markdown, mdown, mkd, txt без скрытых, параметр `files.all` показывает все.
- Управление клавишами и мышью; изменения на диске видны через 2 с. При несохранённых правках открытие другого файла требует подтверждения.

### Настройки

- F9: диалог настроек. Изменения применяются сразу, Enter записывает их в файл конфигурации с сохранением комментариев, Esc отменяет.
- Из диалога открывается и сам файл конфигурации: в нём задаются клавиши и собственные темы.

### Файлы

- Кодировки: UTF-8, UTF-16 LE/BE, CP1251, CP866, KOI8-R; автоопределение или ручной выбор.
- Кодировка, BOM и переводы строк сохраняются, в том числе смешанные. Файл без правок записывается побайтно.
- Запись через временный файл и переименование. Сохраняются права и символические ссылки, в Linux также ACL и расширенные атрибуты.

### Сохранность данных

- Копия несохранённых правок через 5 с, восстановление после сбоя.
- Проверка изменений файла на диске каждые 2 с и перед записью.
- Резервная копия `.bak` при первом сохранении за сеанс (отключаемая).
- Автосохранение (по умолчанию выключено).

### Сеть

Единственное обращение к сети: команда `ruconmd --update`. Фоновых запросов и автоматической проверки обновлений нет.

## Установка

Скрипты ставят программу в каталог текущего пользователя без прав администратора, сверяют SHA-256 архива и добавляют каталог в PATH. Версия: последний окончательный выпуск, при его отсутствии последний предварительный.

Linux (`~/.local/bin`):

```
curl -fsSL https://raw.githubusercontent.com/nttlman23/ruconmd/main/install.sh | sh
```

Windows (`%LOCALAPPDATA%\Programs\ruconmd`), PowerShell 5.1 и новее:

```
irm https://raw.githubusercontent.com/nttlman23/ruconmd/main/install.ps1 | iex
```

Параметры скачанного скрипта:

| `install.sh` | `install.ps1` | Назначение |
|---|---|---|
| `--version X.Y.Z` | `-Version X.Y.Z` | заданная версия |
| `--dir КАТАЛОГ` | `-Dir КАТАЛОГ` | каталог установки |
| `--from КАТАЛОГ` | `-From КАТАЛОГ` | архив и `SHA256SUMS` из каталога, без сети; требует версию |
| `--no-path` | `-NoPath` | не менять PATH |
| `--uninstall` | `-Uninstall` | удалить; настройки и копии восстановления остаются |

Установка вручную: архив со страницы [выпусков](https://github.com/nttlman23/ruconmd/releases). Исполняемые файлы не подписаны, возможно предупреждение Windows SmartScreen.

## Обновление

```
ruconmd --update
```

1. Запрос списка выпусков у GitHub. Предварительные версии ставятся только поверх предварительных.
2. Загрузка исполняемого файла по HTTPS и сверка с `SHA256SUMS` выпуска.
3. Замена файла программы. Если он недоступен для записи, загрузка не выполняется.

Контрольная сумма хранится в том же выпуске, что и файл: она обнаруживает порчу при загрузке, но не подмену при взломе учётной записи GitHub. То же относится к скриптам установки.

## Командная строка

```
ruconmd [ФАЙЛ | КАТАЛОГ] [--view] [--line N] [--encoding ИМЯ] [--lang ru|en] [--config ПУТЬ]
ruconmd --keys [--lang ru|en] [--config ПУТЬ]
ruconmd --update [--lang ru|en] [--config ПУТЬ]
ruconmd --help | --version
```

| Параметр | Действие |
|---|---|
| `ФАЙЛ` | открыть файл; несуществующий создаётся при первом сохранении |
| `КАТАЛОГ` | открыть панель файлов |
| `--view` | начать в режиме просмотра |
| `--line N` | перейти к строке N |
| `--encoding ИМЯ` | кодировка файла: `utf-8`, `utf-16le`, `utf-16be`, `cp1251`, `cp866`, `koi8-r` |
| `--lang` | язык интерфейса, по умолчанию из локали |
| `--config ПУТЬ` | файл конфигурации |
| `--keys` | вывод событий клавиатуры, получаемых от терминала |
| `--update` | обновление программы |

## Клавиши по умолчанию

| Действие | Клавиши |
|---|---|
| Правка / просмотр | F5, Ctrl+E |
| Сохранить, сохранить как | Ctrl+S или F2, F12 |
| Выход | Ctrl+Q, F10 |
| Панель файлов | F4, Ctrl+O |
| Настройки | F9 |
| Отменить, повторить | Ctrl+Z, Ctrl+Y |
| Копировать, вырезать, вставить, выделить всё | Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+A |
| Найти, далее, ранее | Ctrl+F, F3, Shift+F3 |
| Заменить | Ctrl+R |
| Оглавление, к строке | Ctrl+T, Ctrl+G |
| Жирный, курсив, ссылка | Ctrl+B, Alt+I, Ctrl+K |
| Кодировка и переводы строк | F8 |
| Справка | F1 |
| Просмотр: выбрать, открыть, отметить, назад | Tab / Shift+Tab, Enter, Пробел, Alt+Влево |

В панели файлов: стрелки, PgUp/PgDn, Home/End; Enter или Пробел открывает файл и раскрывает каталог; Влево и Вправо сворачивают и раскрывают; Backspace переходит на каталог выше; буква ищет имя; Esc или Tab возвращает к тексту.

Сочетания с Ctrl и Alt сопоставляются по положению клавиши и действуют в русской раскладке, если терминал передаёт модификатор вместе с кириллицей. Иначе для сохранения, выхода и смены режима служат F-клавиши.

## Конфигурация

| ОС | Путь |
|---|---|
| Linux | `$XDG_CONFIG_HOME/ruconmd/config.toml`, по умолчанию `~/.config/ruconmd/config.toml` |
| Windows | `%APPDATA%\ruconmd\config.toml` |

Формат TOML. Основные параметры меняются в программе (F9), путь к файлу показан в диалоге. Все параметры со значениями по умолчанию: [config.example.toml](config.example.toml). Ошибочный параметр заменяется значением по умолчанию с предупреждением.

## Известные ограничения

- Картинки: в Konsole, tmux и screen только подпись; в Windows автоопределения нет, требуется `images = "sixel"` в разделе `[preview]`.
- Windows: при закрытии окна терминала теряется до 5 с правок; ACL файла при сохранении может не сохраниться.
- Строка длиной 10 МБ: задержка ввода около 0,14 с.
- Mermaid: вывод исходного кода.

## Сборка

Требуются Rust 1.90 или новее и компилятор C.

```
cargo build --release
```

Статический файл для Linux (цель `x86_64-unknown-linux-musl`, пакет `musl-tools`):

```
cargo build --release --target x86_64-unknown-linux-musl
```
