# ruconmd

Консольный редактор Markdown для Linux и Windows. Одна клавиша переключает редактирование и просмотр на весь экран.

Состояние: предварительная версия 0.1.0-beta.2, см. [изменения](CHANGELOG.md). В Linux проверяется автотестами и вручную. В Windows автотесты проходят в CI (псевдотерминал ConPTY), в Windows Terminal основные сценарии проверены вручную.

## Возможности

- Редактор: отмена, выделение клавишами и мышью, поиск и замена с regex, продолжение списков, подсветка разметки.
- Просмотр: CommonMark и GFM, подсветка кода, ссылки, оглавление, отметка задач, формулы LaTeX в Unicode, локальные картинки (Kitty, iTerm2, Sixel).
- Файлы: UTF-8, UTF-16, CP1251, CP866, KOI8-R; кодировка, BOM и переводы строк сохраняются.
- Сохранность: восстановление после сбоя, `.bak`, контроль чужих изменений, автосохранение по желанию.
- Программа обращается к сети только по команде `ruconmd --update`, сама обновлений не ищет. Ссылки http, https и mailto открывает системное приложение.

## Установка

Нужна 64-разрядная система x86_64. Права администратора не нужны: программа ставится в каталог пользователя и добавляется в PATH. Контрольная сумма сверяется.

Linux, в `~/.local/bin`:

```
curl -fsSL https://raw.githubusercontent.com/nttlman23/ruconmd/main/install.sh | sh
```

Windows, в `%LOCALAPPDATA%\Programs\ruconmd`, в окне PowerShell:

```
irm https://raw.githubusercontent.com/nttlman23/ruconmd/main/install.ps1 | iex
```

Скрипты ставят последний окончательный выпуск, а пока его нет, последний предварительный. Скачанному скрипту можно задать версию, каталог, отказ от PATH и удаление: `--version`, `--dir`, `--no-path`, `--uninstall` (в Windows `-Version`, `-Dir`, `-NoPath`, `-Uninstall`).

Без скрипта: скачайте архив на странице [выпусков](https://github.com/nttlman23/ruconmd/releases) и распакуйте, внутри один исполняемый файл и лицензии.

## Обновление

```
ruconmd --update
```

Команда запрашивает у GitHub список выпусков, загружает новую версию по HTTPS, сверяет её с `SHA256SUMS` и заменяет файл программы. Предварительные версии ставятся только поверх предварительных. Если каталог программы недоступен для записи, она не меняется.

Сумма лежит там же, где файл: она защищает от порчи при загрузке, но не от взлома учётной записи GitHub. То же относится к скриптам установки.

## Сборка

Нужен Rust 1.90 или новее.

```
cargo build --release
```

Один файл без зависимостей для Linux (нужны цель `x86_64-unknown-linux-musl` и `musl-tools`):

```
cargo build --release --target x86_64-unknown-linux-musl
```

## Запуск

```
ruconmd файл.md                  открыть для правки
ruconmd --view файл.md           открыть для просмотра
ruconmd --line 40 файл.md        перейти к строке
ruconmd --encoding cp866 файл.md задать кодировку
ruconmd --keys                   показать, что передаёт терминал
ruconmd --update                 обновить программу
```

## Клавиши

| Действие | Клавиши |
|---|---|
| Правка / просмотр | F5, Ctrl+E |
| Сохранить, сохранить как | Ctrl+S или F2, F12 |
| Выход | Ctrl+Q, F10 |
| Отменить, повторить | Ctrl+Z, Ctrl+Y |
| Найти, далее, ранее | Ctrl+F, F3, Shift+F3 |
| Заменить | Ctrl+R |
| Оглавление, к строке | Ctrl+T, Ctrl+G |
| Жирный, курсив, ссылка | Ctrl+B, Alt+I, Ctrl+K |
| Кодировка и переводы строк | F8 |
| Справка | F1 |
| В просмотре: выбрать, открыть, отметить, назад | Tab, Enter, Пробел, Alt+Влево |

Сочетания работают и в русской раскладке, если терминал передаёт Ctrl вместе с кириллицей.

## Настройка

Скопируйте [config.example.toml](config.example.toml) в `~/.config/ruconmd/config.toml` или `%APPDATA%\ruconmd\config.toml`. Язык, темы, клавиши и параметры описаны в самом файле.

## Известные ограничения

- В Konsole, tmux и screen картинки показываются подписью. В Windows их надо включить: `images = "sixel"`.
- В Windows при закрытии окна теряется до 5 секунд правок, особые права доступа к файлу (ACL) при сохранении могут не сохраниться.
- Файл из одной строки на 10 МБ редактируется с задержкой около 0,14 с.
- Mermaid показывается кодом.
