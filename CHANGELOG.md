# Изменения

## Не выпущено

- Панель файлов: `ruconmd КАТАЛОГ`, F4 или Ctrl+O.
- Диалог настроек: F9. Конфиг меняется с сохранением комментариев, его можно открыть из диалога.
- Файл, изменённый другой программой, перечитывается сам, если окно не в фокусе и своих правок нет. Если правки есть, программа спрашивает, чью версию оставить.
- `ruconmd --update` в Windows учитывает системный прокси, а в ошибке сети называет сервер и прокси.
- Справка F1 на обычном экране видна целиком, в две колонки.

## 0.1.0-beta.3

**Добавлено:**

- Скрипты установки для Linux и Windows, см. README.
- Команда `ruconmd --update` обновляет программу. Сама программа обновлений не ищет и в сеть не ходит. С 0.1.0-beta.2 и раньше обновляйтесь вручную или скриптом.

**Исправлено:**

- Остатки записи копии восстановления, прерванной сбоем, убираются при следующем запуске, если они старше часа.
- В Linux `.bak` получает группу файла, а если её нельзя повторить, доступен только владельцу.

**Файлы:** архивы `ruconmd-…-linux-x86_64.tar.gz` (статический файл, без зависимостей) и `ruconmd-…-windows-x86_64.zip`; `install.sh` и `install.ps1`; отдельные файлы `.bin` и `.exe` для `--update`. Контрольные суммы в `SHA256SUMS`. Файлы не подписаны, Windows SmartScreen может предупредить.

**Проверено:** автотесты в Linux и Windows, скрипты установки в CI без сети. Вручную эта версия не проверялась, замена программы командой `--update` проверена только автотестами. Остальные известные ограничения те же, что у 0.1.0-beta.1.

## 0.1.0-beta.2

Исправления сохранности данных, рекомендуется всем, у кого 0.1.0-beta.1.

**Исправлено:**

- «Заменить все», жирный, курсив и ссылка больше не меняют переводы строк внутри затронутого текста.
- В Linux при сохранении остаются ACL и расширенные атрибуты. Раньше ACL терялся, и файл мог открыться группе владельца.
- Сбой фонового потока не портит экран, сообщение выводится после выхода. Неудачное построение просмотра не повторяется без конца.
- «Сохранить как» узнаёт открытый файл под другой записью пути и проверяет чужие изменения и потери при чтении.
- Минимальная версия Rust 1.90: прежняя, 1.89, не подходила зависимостям.

**Файлы:** `ruconmd-…-linux-x86_64.tar.gz` (статический, без зависимостей) и `ruconmd-…-windows-x86_64.zip`. Контрольные суммы в `SHA256SUMS`. Файлы не подписаны, Windows SmartScreen может предупредить.

**Проверено:** автотесты в Linux и Windows. Вручную эта версия не проверялась, список ручных проверок и известные ограничения те же, что у 0.1.0-beta.1.

## 0.1.0-beta.1

Первая публичная версия, предварительная. Консольный редактор Markdown для Linux и Windows с полноэкранным переключением правки и просмотра по F5 или Ctrl+E.

**Файлы:** `ruconmd-…-linux-x86_64.tar.gz` (статический, без зависимостей) и `ruconmd-…-windows-x86_64.zip`. Контрольные суммы в `SHA256SUMS`. Файлы не подписаны, Windows SmartScreen может предупредить.

**Проверено:** автотесты в Linux и Windows; вручную Windows Terminal (клавиши, русская раскладка, вставка, восстановление, вид таблиц) и один терминал Linux (сочетания клавиш, буфер обмена).

**Вручную не проверено:** Konsole, Kitty, Alacritty, WezTerm и GNOME Terminal по полному списку; показ картинок в настоящем терминале.

**Известные ограничения:**

- В Windows картинки включаются вручную: `images = "sixel"` в разделе `[preview]`. В Konsole, tmux и screen они показываются подписью.
- В Windows при закрытии окна теряется до 5 секунд правок, особые права доступа к файлу (ACL) при сохранении могут не сохраниться.
- Файл из одной строки на 10 МБ редактируется с задержкой около 0,14 с.
- Mermaid показывается кодом.
