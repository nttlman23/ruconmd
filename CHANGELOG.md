# Изменения

## 0.1.0-beta.1

Первая публичная версия, предварительная. Консольный редактор Markdown для Linux и Windows с полноэкранным переключением правки и просмотра по F5 или Ctrl+E.

**Файлы:** `ruconmd-…-linux-x86_64.tar.gz` (статический, без зависимостей) и `ruconmd-…-windows-x86_64.zip`. Контрольные суммы в `SHA256SUMS`. Файлы не подписаны, Windows SmartScreen может предупредить.

**Проверено:** автотесты в Linux и Windows; вручную Windows Terminal (клавиши, русская раскладка, вставка, восстановление, вид таблиц) и один терминал Linux (сочетания клавиш, буфер обмена).

**Вручную не проверено:** Konsole, Kitty, Alacritty, WezTerm и GNOME Terminal по полному списку; показ картинок в настоящем терминале.

**Известные ограничения:**

- В Windows картинки включаются вручную: `images = "sixel"` в разделе `[preview]`. В Konsole, tmux и screen они показываются подписью.
- В Windows при закрытии окна теряется до 5 секунд правок, особые права доступа к файлу (ACL) при сохранении могут не сохраниться.
- Файл из одной строки на 10 МБ редактируется с задержкой около 0,14 с.
- Mermaid показывается кодом.
