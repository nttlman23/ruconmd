# ruconmd: спецификация, версия 1

Консольный редактор Markdown на Rust для Linux и Windows с полноэкранным переключением «редактирование / просмотр».

Пометка **[П]** означает решение, предложенное при составлении спецификации и не обсуждавшееся отдельно. Остальное следует из ответов заказчика.

## 1. Границы версии

Входит: один открытый файл, панель файлов (раздел 18), управление в стиле nano/VS Code, просмотр CommonMark + GFM, картинки, формулы и Mermaid текстом, темы, переназначение клавиш, русский и английский интерфейс.

Не входит: вкладки, split и live preview, vim-раскладка, сетевые запросы (кроме команды обновления, раздел 17), плагины, экспорт, графический рендер Mermaid, пакеты deb/rpm/winget.

## 2. Запуск

```
ruconmd [ФАЙЛ | КАТАЛОГ] [--view] [--line N] [--encoding ИМЯ] [--lang ru|en] [--config ПУТЬ]
ruconmd --keys [--lang ru|en] [--config ПУТЬ]
ruconmd --update [--lang ru|en] [--config ПУТЬ]
ruconmd --help | --version
```

- Несуществующий файл: пустой буфер, файл создаётся при первом сохранении. **[П]**
- Без аргумента: безымянный буфер, имя запрашивается при сохранении. **[П]**
- `--view`: старт в режиме просмотра. **[П]**
- `--keys`: проверка клавиш терминала; по выходу печатает журнал без содержимого вставок (набранные клавиши в нём видны). **[П]**

## 3. Экран

Строка заголовка (имя, признак изменений), рабочая область, строка состояния (режим, строка:колонка, кодировка, LF/CRLF, подсказки). Сообщения и запросы выводятся в нижней строке, оглавление и справка во всплывающем окне. **[П]**

## 4. Режимы

- Переключение: **F5** или **Ctrl+E**, из любого режима в другой.
- Позиция сохраняется: после переключения виден тот же блок документа.
- Просмотр показывает текущий буфер, включая несохранённые правки.
- Текст из просмотра не правится, кроме чекбоксов.

## 5. Клавиши по умолчанию

Все команды переназначаются в конфиге. Исключены Ctrl+M, Ctrl+I и Ctrl+H: в терминалах они могут быть неотличимы от Enter, Tab и Backspace. **[П]** (кроме переключения режимов)

| Команда | Клавиши |
|---|---|
| Переключить режим | F5, Ctrl+E |
| Сохранить / сохранить как | Ctrl+S, F2 / F12 |
| Выход | Ctrl+Q, F10 |
| Панель файлов | F4, Ctrl+O |
| Настройки | F9 |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Копировать / вырезать / вставить | Ctrl+C / Ctrl+X / Ctrl+V |
| Выделить всё | Ctrl+A |
| Найти / следующее / предыдущее | Ctrl+F / F3 / Shift+F3 |
| Заменить | Ctrl+R |
| К строке | Ctrl+G |
| Оглавление | Ctrl+T |
| Жирный / курсив / ссылка | Ctrl+B / Alt+I / Ctrl+K |
| Кодировка и переводы строк | F8 |
| Справка | F1 |

В просмотре: стрелки, PgUp/PgDn, Home/End для прокрутки; Tab/Shift+Tab выбирают ссылку или чекбокс; Enter открывает ссылку; Пробел переключает чекбокс; Alt+Влево возвращает назад.

**Русская раскладка.** Сочетания Ctrl+буква и Alt+буква должны срабатывать и при русской раскладке: кириллический символ сопоставляется клавише по позиции (ы = S, у = E). Если терминал не передаёт такое сочетание вовсе, для сохранения, выхода и смены режима есть F-клавиши. **[П]**

## 6. Редактор

- Ввод Unicode, движение курсора по графемам, верная ширина широких символов.
- Выделение с Shift и мышью; клик ставит курсор, колесо прокручивает.
- Undo/redo с группировкой набора в один шаг.
- Буфер обмена: системный, при недоступности внутренний. Без выделения копируется и вырезается вся строка. **[П]**
- Tab вставляет пробелы до позиции табуляции. Home/End идут сначала к краю экранной строки, затем к краю строки текста. **[П]**
- Подсветка Markdown в исходном тексте, построчно: выделение, перешедшее на следующую строку, и строки длиннее 8 КБ не подсвечиваются. **[П]**
- Помощь при вводе: Enter продолжает список, нумерацию, чекбокс или цитату; Enter на пустом пункте завершает список; Tab/Shift+Tab меняют отступ; Ctrl+B, Alt+I, Ctrl+K оборачивают выделение, повторное нажатие снимает жирный и курсив. В блоках кода помощь не действует, нумерация следующих пунктов не пересчитывается. **[П]** (кроме состава возможностей)
- При вставке помощь при вводе отключается, вставка отменяется одним шагом. **[П]**
- Поиск и замена: учёт регистра (Alt+C), regex с группами (Alt+R), замена по одной и всех. «Все» заменяет совпадения, до которых ещё не дошли, одним шагом отмены; поиск и замена идут по кругу, замена останавливается там, где начали. **[П]** (кроме состава возможностей)
- Перенос длинных строк на экране и номера строк, отключаются в конфиге.

## 7. Просмотр

- CommonMark: заголовки, абзацы, списки, цитаты, код, ссылки, разделители.
- GFM: таблицы, чекбоксы, зачёркивание, автоссылки, сноски. Таблица шире экрана: перенос внутри ячеек. **[П]**
- Блоки кода: подсветка по языку, неизвестный язык выводится без неё. Подсвечиваются только показанные строки, не дольше 15 мс за кадр; после строки длиннее 2000 байт блок выводится без цвета. **[П]**
- Предупреждения GFM (`[!NOTE]` и другие) и метаданные YAML в начале файла. Сноски выводятся там, где определены. **[П]**
- Адрес выбранной ссылки виден в строке состояния. **[П]**
- Щелчок мышью открывает ссылку и переключает чекбокс. **[П]**
- Картинки: только локальные PNG/JPEG/GIF (первый кадр)/WebP через Kitty, Sixel или iTerm2. Без поддержки графики, а также для удалённых адресов: alt-текст и ссылка. Форматы **[П]**.
- Картинка показывается, если абзац состоит только из картинок; в тексте, таблицах и заголовках остаётся alt-текст. Не выше 30 строк, маленькие не растягиваются; под картинкой подпись. Пределы: файл 64 МБ, сторона 16384 точки, 512 МБ памяти. Формат определяется по содержимому. **[П]**
- Выбор протокола: опрос терминала при запуске, не дольше 1 с. Kitty, затем iTerm2 (iTerm, WezTerm, mintty, Rio), затем Sixel. В Konsole, tmux и screen картинки текстом. В Windows автоопределения нет, включается `preview.images = "sixel"`. **[П]**
- Формулы `$...$` и `$$...$$`: преобразование в Unicode; непреобразуемое выводится исходным LaTeX. Дроби в строку, матрицы, `cases` и `aligned` в несколько строк, блоки ` ```math ` тоже. **[П]** (кроме первого предложения)
- Mermaid: подсвеченный код с подписью «mermaid».
- HTML: показывается как текст, не исполняется. **[П]**
- Ссылки: якоря внутри документа; http/https/mailto в системном приложении; локальный md открывается вместо текущего файла (при несохранённых правках запрос). Остальные схемы, локальные файлы других типов и сетевые пути (`//сервер`, `\\сервер`) не открываются; несуществующий файл по ссылке не создаётся. **[П]**
- Оглавление со всеми заголовками, доступно в обоих режимах.
- Чекбокс меняет `[ ]` / `[x]` в исходном тексте, действие отменяется через undo.
- Поиск по отрисованному тексту с подсветкой совпадений.

## 8. Файлы и кодировки

- UTF-8 (с BOM и без), UTF-16 LE/BE, CP1251, CP866, KOI8-R. Автоопределение, ручной выбор через F8 или `--encoding`.
- Сохранение в исходной кодировке, BOM и LF/CRLF сохраняются. Смешанные переводы строк не нормализуются без команды, в том числе при замене. **[П]**
- Если символы непредставимы в кодировке файла: запрос «сохранить в UTF-8 / отменить», молчаливая замена запрещена. **[П]**
- Запись через временный файл и переименование, права доступа (в Linux и ACL с расширенными атрибутами) и символические ссылки сохраняются. При жёстких ссылках и при отказе в доступе к каталогу, владельцу или атрибутам запись идёт на место, без атомарности. **[П]**
- Файл, который не восстанавливается из прочитанного текста побайтно (повреждён или не та кодировка), записывается только с подтверждением. **[П]**
- Каналы и устройства не открываются. **[П]**
- Файлы до 10 МБ без заметных задержек, более крупные с предупреждением.

## 9. Защита данных

- **Восстановление:** несохранённые правки пишутся через 5 с **[П]** в каталог состояния программы; после сбоя при открытии предлагается восстановить. Удаляется после сохранения или штатного выхода. Каталог: `~/.local/state/ruconmd/recovery` (`$XDG_STATE_HOME`), Windows `%LOCALAPPDATA%\ruconmd\recovery`; в Linux доступен только владельцу. Копия живого сеанса защищена блокировкой и другому окну не предлагается. Недописанные копии прерванных сеансов старше часа убираются при запуске. **[П]**
- **Внешние изменения:** проверка раз в 2 с и перед записью **[П]**; выбор «оставить нашу версию / взять стороннюю / сохранить как». Если окно терминала не в фокусе и своих правок нет, файл перечитывается сам; изменение перед возвращением фокуса тоже считается фоновым. При своих правках вопрос задаётся всегда. Терминал, который не сообщает о фокусе, считается в фокусе. Перечитывания подряд составляют один шаг отмены.
- **Резервная копия:** `file.md.bak` при первом сохранении сеанса, включена по умолчанию, отключаема. Права и группа как у файла, а если группу или ACL повторить нельзя, копия доступна только владельцу; символическая ссылка на месте копии заменяется; если копию создать нельзя, файл сохраняется с предупреждением. **[П]**
- **Автосохранение:** по умолчанию выключено. Приостанавливается при конфликте с внешними изменениями. **[П]**
- Выход с правками: «сохранить / не сохранять / отмена».
- При панике терминал возвращается в исходное состояние, файл восстановления записывается. В Linux то же при SIGTERM, SIGHUP, SIGINT и закрытии окна терминала; в Windows при закрытии окна теряется не более 5 с правок. **[П]** (кроме паники)
- Перечитывание файла и восстановление отменяются через undo. **[П]**

## 10. Конфигурация

Linux: `$XDG_CONFIG_HOME/ruconmd/config.toml` (или `~/.config`), Windows: `%APPDATA%\ruconmd\config.toml`. Ошибка в конфиге не мешает запуску: сообщение и значения по умолчанию; ошибочный параметр не отменяет остальные, все предупреждения повторяются при выходе. Список клавиш заменяет клавиши команды целиком; выход и смену режима оставить без клавиш нельзя. Полный пример: `config.example.toml`. **[П]** (кроме первого предложения)

```toml
language = "auto"          # auto | ru | en
theme = "dark"             # dark | light | имя из [themes.*]

[editor]
tab_width = 4
wrap = true
line_numbers = true

[preview]
max_width = 100            # 0 = вся ширина
images = true              # true | false | "kitty" | "sixel" | "iterm2"

[save]
backup = true
autosave = false
autosave_delay_sec = 5

[files]
all = false
width = 30

[keys]
toggle_mode = ["f5", "ctrl+e"]

[themes.my]
base = "dark"
heading = "#7aa2f7"
```

## 11. Платформы

- Обязательная проверка: Windows Terminal (Windows 10/11); GNOME Terminal, Konsole, Kitty, Alacritty, WezTerm.
- conhost, tmux, SSH и tty: по возможности, без гарантий.
- Цвет: truecolor, при отсутствии 256/16 цветов. Тёмная тема берёт фон терминала, светлая задаёт свой. **[П]**

## 12. Технические решения [П]

| Задача | Выбор |
|---|---|
| Терминал и интерфейс | `crossterm`, `ratatui` |
| Буфер текста | `ropey` 1.6 (2.0 в бете), `unicode-segmentation`, `unicode-width` |
| Разбор Markdown | `pulldown-cmark` (смещения в исходнике нужны для позиции и чекбоксов), `linkify` для автоссылок |
| Поиск | `regex` |
| Завершение по сигналам | `signal-hook` (только Unix) |
| Открытие ссылок | `xdg-open`, в Windows `rundll32 url.dll`, без оболочки |
| Подсветка кода | `syntect` с `fancy-regex`, без зависимости от C; описания языков `two-face` (TOML, TypeScript, Dockerfile, Kotlin) |
| Картинки | `ratatui-image` 11 (кодирование и срезы, опрос терминала свой), `image`, `rustix` (только Unix) |
| Кодировки | `encoding_rs`, `chardetng`; запись UTF-16 своя |
| Обновления | `ureq` с `rustls` (корневые сертификаты внутри), `serde_json`, `semver`, `sha2` |
| Буфер обмена, конфиг, CLI | `arboard`, `serde` + `toml`, `toml_edit` (запись с сохранением комментариев), `clap` |

Архитектура: нажатие клавиши -> раскладка -> команда -> изменение состояния -> отрисовка. Ядро (буфер, команды, разбор, файлы) не зависит от терминала и тестируется отдельно. Разбор для просмотра идёт в фоновом потоке. Ввод читает отдельный поток: `crossterm` 0.29 зацикливается, если терминал исчез. Минимальная версия Rust 1.90.

## 13. Критерии приёмки

- Открытие файла 10 МБ не дольше 1 с, отклик на ввод не дольше 50 мс. **[П]** *Этап 2:* 24–49 мс и менее 5 мс на обычных строках; одна строка 1 МБ: 14 мс; одна строка 10 МБ: около 140 мс, вне критерия.
- Переход в просмотр: 1 МБ не дольше 300 мс; 10 МБ не дольше 2 с с индикатором, ввод не блокируется. **[П]** *Этап 3:* около 60 мс и 0,6 с; первый переход в конец 10 МБ в редакторе 18 мс. *Этап 4, 10 МБ:* поиск 7–33 мс, замена всех 10 тыс. совпадений 58 мс; вне критерия 50 мс разовые действия: оглавление 170 мс, отступ всего файла 440 мс.
- Открыть и сохранить без правок: файл совпадает побайтно, для всех кодировок и переводов строк.
- Аварийное завершение теряет не более 5 с правок.
- Программа не создаёт сетевых соединений, кроме команды `--update`.
- Тесты: модульные для ядра, отрисовка через `TestBackend`, собранная программа в псевдотерминале (`tests/terminal.rs`, в Windows через ConPTY), ссылки в документации, CI на Linux и Windows.

## 15. Риски

1. **Вставка в Windows:** терминал может передать вставку как поток нажатий, тогда её надо распознавать по скорости ввода. *Этап 1:* `crossterm` 0.29 события вставки в Windows не создаёт; распознавание реализовано и покрыто модульными тестами, проходит в CI (ConPTY); вставка в Windows Terminal проверена заказчиком, замечаний нет.
2. **Русская раскладка:** передача Ctrl+кириллица зависит от терминала. *Этап 1:* сопоставление по позиции реализовано; разбор последовательностей в Linux проверен на псевдотерминале, в терминале Linux заказчика Ctrl+S, Ctrl+E и Ctrl+Q распознаются, Ctrl+Q и после ввода «ы»; F10 и вставка через Ctrl+Shift+V там не подтверждены. В Windows Terminal русская раскладка проверена заказчиком, замечаний нет. Остальные терминалы не проверены (`ruconmd --keys`). Терминал, который шлёт Ctrl+Ы как обычную «ы», отличить нельзя, остаются F-клавиши.
3. **Картинки:** определение графических возможностей терминала в Windows и работа Sixel, проверяются отдельным прототипом. *Этап 6:* протоколы и очистка экрана проверены на псевдотерминале, показ в реальных терминалах нет; в Windows определить поддержку программно нельзя.
4. **musl и буфер обмена:** работа `arboard` в статической сборке под X11 и Wayland.

## 17. Установка и обновление

Добавлено по просьбе заказчика после 0.1.0-beta.2. Пометка **[П]** означает то же, что выше.

- **Установка:** `install.sh` (Linux x86_64) и `install.ps1` (Windows x86_64, PowerShell 5.1 и новее) ставят программу в каталог пользователя без прав администратора, сверяют SHA-256, добавляют каталог в PATH, умеют удалять. Настройки и копии восстановления при удалении остаются. Без сети: `--from`. **[П]** (кроме выбора скриптов)
- **Обновление:** только командой `ruconmd --update`, по решению заказчика автоматической проверки и предложений нет. Список выпусков и файл берутся с GitHub (только HTTPS, файл не больше 64 МБ), сверяется сумма из `SHA256SUMS`, затем заменяется файл программы. Предварительные выпуски ставятся только поверх предварительных. Если файл нельзя заменить, он не загружается. В Windows прежний файл отодвигается в `.old` и убирается при следующем запуске. Подписи нет: сумма не защищает от взлома учётной записи GitHub. **[П]** (кроме способа запуска)

## 18. Панель файлов и настройки

Добавлено по просьбе заказчика после 0.1.0-beta.3.

- **Запуск:** `ruconmd КАТАЛОГ` открывает панель слева, документ пустой безымянный. Из файла панель открывается в его каталоге, открытый файл выбран. **[П]** (кроме открытия каталога)
- **Содержимое:** каталоги первыми, затем файлы md, markdown, mdown, mkd, txt; скрытое и остальное по параметру `files.all`. Каналы, устройства и битые ссылки не показываются, из каталога не больше 5000 записей. Показанные каталоги проверяются раз в 2 с. **[П]**
- **Клавиши:** F4 или Ctrl+O открывает, переводит в панель, а из неё закрывает. Правка текста из панели невозможна, команды поиска и перехода сначала возвращают к тексту. **[П]**
- **Открытие файла:** вместо текущего, при несохранённых правках запрос. **[П]**
- **Узкий экран:** если рядом с панелью не остаётся 30 колонок, она занимает всё место, пока выбрана. **[П]**
- **Новый файл:** пока панель показана, имя безымянного документа запрашивается в её каталоге. **[П]**
- **Настройки:** F9, диалог. Изменения действуют сразу, кроме картинок (со следующего запуска); Enter записывает изменённые параметры в конфиг, остальное в нём не меняется; Esc отменяет. Конфиг с ошибкой не переписывается. Клавиши и свои темы меняются в самом файле, он открывается из диалога, а если его нет, создаётся из образца. **[П]** (кроме диалога по клавише)
