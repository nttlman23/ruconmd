# Ручная проверка в терминале

Автотесты проверяют программу в псевдотерминале. Здесь то, что видно только глазами и на настоящей клавиатуре.

Обязательные терминалы: Windows Terminal (Windows 10 и 11), GNOME Terminal, Konsole, Kitty, Alacritty, WezTerm.

Перед проверкой скопируйте каталог `docs/check` в другое место: некоторые пункты меняют файлы. Далее `sample.md` означает копию.

## 1. Клавиши

Запустите `ruconmd --keys --lang ru`. Нажмите перечисленное, дважды Esc и сохраните журнал. Набранные клавиши в нём видны, а текст вставки виден, если вставка не распознана, поэтому вставляйте несекретное.

- [ ] Латинская раскладка: Ctrl+S, Ctrl+E, Ctrl+Q, Alt+I, Alt+Влево
- [ ] Русская раскладка: `ы`, Ctrl+Ы, Ctrl+У, Ctrl+Й, Alt+Ш
- [ ] F1, F2, F3, Shift+F3, F5, F8, F10, F12
- [ ] Shift+стрелки, Ctrl+стрелки, Ctrl+Home, Ctrl+End, Shift+Tab
- [ ] Вставка трёх строк каждым способом, который есть в терминале: в журнале одна «вставка»

## 2. Редактор

Откройте `ruconmd --lang ru sample.md`.

- [ ] Кириллица, `日本語` и эмодзи набираются, курсор стоит там, где ожидается
- [ ] Вставка списка из другой программы не удваивает маркеры и отменяется одним Ctrl+Z
- [ ] Копирование в другую программу и из неё
- [ ] Мышь: щелчок, выделение протягиванием, колесо
- [ ] Изменение размера окна, в том числе до очень узкого
- [ ] Enter продолжает список, на пустом пункте завершает его
- [ ] Ctrl+F, F3, Ctrl+R

## 3. Просмотр

Нажмите F5.

- [ ] Рамки таблицы ровные, в том числе в строках с `日本語` и `☐ ☑ ▌ ▣`
- [ ] Цвета читаются на вашем фоне; то же с `theme = "light"`
- [ ] Tab выбирает ссылки, Enter открывает раздел, второй файл и сайт в браузере
- [ ] Запрещённая ссылка не открывается
- [ ] Alt+Влево возвращает назад
- [ ] Пробел и щелчок мышью переключают задачу
- [ ] Формулы читаются, матрица ровная
- [ ] Картинка: показана либо заменена подписью. Если показана: при прокрутке, F1 и F5 не остаётся следов

Ожидается: Kitty и WezTerm показывают картинку, Alacritty и Konsole подпись, GNOME Terminal зависит от сборки. В Windows Terminal 1.22+ картинка появляется с `images = "sixel"` в конфиге.

## 4. Сохранность

- [ ] Наберите текст, подождите 6 секунд, завершите процесс принудительно. При открытии предлагается восстановление
- [ ] Наберите текст и сразу закройте окно терминала. Linux: текст восстановлен. Windows: потеряно не больше 5 секунд набора
- [ ] Измените файл другой программой: появляется вопрос
- [ ] После выхода терминал в порядке: курсор виден, ввод отображается
